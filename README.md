# playground

Testing modules and experiments.

## GPS Kalman Filter Example

The file `gps_kalman.py` demonstrates a Kalman Filter that fuses
synthetic GPS and IMU data to track a vehicle in meters.  Run it with:

```bash
python gps_kalman.py
```

The script will display a plot of the raw GPS positions, filtered
trajectory and residual diagnostics.

You can also open `gps_kalman_demo.ipynb` in Jupyter to run the same
simulation interactively.
